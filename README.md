# PDF Toolkit

A comprehensive toolkit for processing and manipulating PDF documents.

## Overview

**PDF Toolkit** (`Pdf-toolkit`) is a utility designed to simplify common PDF processing tasks such as merging, splitting, extracting text, compressing, and managing pages.

## Features & Roadmap

- [ ] **PDF Merging:** Combine multiple PDF documents into a single file.
- [ ] **PDF Splitting:** Split a PDF document into individual pages or specific page ranges.
- [ ] **Text & Image Extraction:** Extract raw text or embedded images from PDF files.
- [ ] **Page Operations:** Rotate, reorder, or delete specific pages.
- [ ] **PDF Compression:** Reduce PDF file sizes for easy sharing.
- [ ] **Security & Encryption:** Add or remove password protection and manage permissions.

## Installation
